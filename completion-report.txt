3. NEWLY CREATED API ROUTES
================================================================================
- src/app/api/students/assignments/route.ts (GET)
    Returns published assignments for courses the student is enrolled in
    (via StudentCourse -> CourseOffering). Marks each assignment completed
    (by studentId/email in completedEmails) and overdue. Auth: student only.
- src/app/api/auth/logout/route.ts (POST)
    Clears the token cookie. Fixes 404s from DashboardHeader, MissionHubHeader,
    and CommunicationHubHeader which called /api/auth/logout.
- src/app/api/maintenance/backfill-student-profiles/route.ts (POST)
    Creates StudentProfile records for student-role Users missing one.
- src/app/api/maintenance/fix-long-usernames/route.ts (POST)
    Shortens usernames longer than 30 characters.

4. PREVIOUSLY INCOMPLETE / BROKEN FEATURES FIXED
================================================================================
- Student dashboard quick-action buttons had no onClick handlers.
  Wired them to /dashboard/student/assignments, /courses, /profile.
- Student dashboard loadAssignments used /api/assignments?studentId=me which is
  admin/manager/mentor-only (403 for students). Switched to /api/students/assignments.
- /dashboard/admin/students showed 0 students because StudentProfile collection
  was empty (demo seed created Users only). Fixed demo seed to also create
  StudentProfile records. Backfilled 3 existing student users.
- StudentProfile edit failed with "username too big" because backfilled usernames
  were student_<mongoId> (>30 chars). Shortened them and added a defensive
  truncation in the PUT handler. Also fixed backfill to generate short usernames.
- Profile completion failed with E11000 duplicate key because backfilled
  StudentProfile already existed. Changed to upsert (findOneAndUpdate).
- Logout returned 404 (no /api/auth/logout). Created the endpoint.
- JWT_SECRET missing from .env.local (only JWT_SECRET_KEY existed). Added
  JWT_SECRET so middleware could load.
- Build error: mission-communication-hub/resources/page.tsx missing "use client".
  Added the directive.
- MongoDB was not running locally; user connected Atlas. Updated MONGODB_URI usage
  (sms-database). Env already had localhost; user switched to Atlas connection.
