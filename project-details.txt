================================================================================
STUDENT MANAGEMENT SYSTEM (SMS) - PROJECT DETAILS
================================================================================
প্রকল্প: Student Management System (sms-web)
ফ্রেমওয়ার্ক: Next.js 15 (App Router) + TypeScript + Tailwind CSS + MongoDB
তারিখ: 2026

================================================================================
১. সাধারণ বর্ণনা
================================================================================
- এটি একটি সম্পূর্ণ স্টুডেন্ট ম্যানেজমেন্ট সিস্টেম।
- ফ্রন্টএন্ড এবং ব্যাকএন্ড একই Next.js অ্যাপে আছে (App Router)।
- ব্যাকএন্ড API রুটগুলো src/app/api ফোল্ডারে আছে।
- ডাটাবেস: MongoDB (Mongoose ODM)।
- অথেনটিকেশন: JWT টোকেন + HTTP-only কুকি।
- রোল-বেজড অ্যাক্সেস কন্ট্রোল আছে।

================================================================================
২. প্রযুক্তি (Tech Stack)
================================================================================
- Next.js 15, React 19, TypeScript
- Tailwind CSS (UI styling)
- MongoDB + Mongoose (ডাটাবেস)
- JWT (jsonwebtoken) + bcryptjs (পাসওয়ার্ড হ্যাশ)
- NextAuth (dependency, কিছু ফিচারে ব্যবহৃত)
- Cloudinary (ফাইল আপলোড)
- Nodemailer (ইমেইল)
- Redux Toolkit (স্টেট ম্যানেজমেন্ট)
- Zod (ভ্যালিডেশন)

================================================================================
৩. ইউজার রোল (User Roles)
================================================================================
- admin: সম্পূর্ণ অ্যাক্সেস ও ম্যানেজমেন্ট।
- developer: ডেভেলপার অ্যাক্সেস।
- manager: সীমিত অ্যাডমিন অ্যাক্সেস।
- sre: SRE অ্যাক্সেস।
- mentor: মেন্টর অ্যাক্সেস (মেন্টরশিপ)।
- student: স্টুডেন্ট সেল্ফ-সার্ভিস পোর্টাল।

================================================================================
৪. অথেনটিকেশন ও রেজিস্ট্রেশন ফ্লো
================================================================================
- লগইন: /login (ইমেইল/ইউজারনেম/ফোন দিয়ে)।
- রেজিস্ট্রেশন: স্টুডেন্টরা ইনভাইটেশন লিংক দিয়ে অ্যাকাউন্ট তৈরি করে।
- পাসওয়ার্ড রিসেট: /forgot-password ও /reset-password।
- প্রথম লগইনে প্রোফাইল সম্পূর্ণ করতে হয় (/profile/complete)।
- JWT টোকেন কুকিতে সংরক্ষিত থাকে; middleware রুট প্রটেক্ট করে।
- পাসওয়ার্ড এক্সপায়ারি: PASSWORD_EXPIRY_DAYS (ডিফল্ট ৩ দিন)।

১২. রান/সেটআপ নির্দেশনা
================================================================================
- .env.local ফাইল তৈরি করতে হবে (MONGODB_URI, JWT_SECRET, NEXTAUTH_SECRET ইত্যাদি)।
- MongoDB চালু থাকতে হবে (লোকাল বা Atlas)।
- ডিপেন্ডেন্সি: npm install
- ডেভ সার্ভার: npm run dev  (http://localhost:3000)
- বিল্ড: npm run build
- প্রোডাকশন: npm start
- বেসিক সিড: POST /api/seed  (অ্যাডমিন ইউজার তৈরি)
- ডেমো সিড: /seed-demo-data পেজ (লগইন প্রয়োজন)

১৫. সমস্যা সমাধান (Troubleshooting)
================================================================================
- JWT_SECRET is not set: .env.local এ JWT_SECRET যোগ করতে হবে।
- MongoDB ECONNREFUSED: MongoDB চালু নেই; লোকাল বা Atlas কানেক্ট করতে হবে।
- invalid signature: পুরানো টোকেন কুকি; /api/auth/clear-token ব্যবহার করতে হবে।
- Login invalid: অ্যাডমিন ইউজার নেই; প্রথমে POST /api/seed রান করতে হবে।
- Demo seed 401: লগইন করা নেই বা পুরানো টোকেন; লগইন করে আবার চেষ্টা করতে হবে।
